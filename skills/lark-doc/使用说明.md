# lark-doc 使用与安装

本目录是 GBro 公开包中可选的 Skill 源码。先读 `SKILL.md` 和 `LICENSE`／`LICENSE.txt`，按当前用户授权使用；Skill 不包含账号、凭据或模型服务权限。

通过仓库 `scripts/install_skills.py --skill lark-doc --destination 目标目录` 预览，确认无冲突后加 `--apply` 安装。不会覆盖已有 Skill；安装后刷新宿主。

依赖、MCP 接入和各工具写入边界见 [GBro 安装说明](https://github.com/BLACKIELF/gbroskill/blob/main/docs/INSTALL.md)。来源与版本见仓库 `dependencies.lock.json`，原作者和许可保留在本目录。本说明由 AiGoodBro 提供，MIT。
