# 包框安全区与画幅过渡

本次将维护者确认的竖版成片做法写入工作流。横视频、竖视频和截图分别定框，尺寸或画幅变化用 0.72 秒平滑过渡。光晕与背景继续按全片时间运行，验收增加左右各裁 8% 的最终编码实帧检查。

现有 9:16 模板、`setRect`／`seek` 接口、72 px 独立字幕和动态光框可直接使用。760 px 框宽和 56 px 光晕外扩是 1080×1920 的已验证参数示例，每段根据素材和安全区定框。

来源为维护者核看的 28 秒包框样片及 96.23 秒完整配音成片。两版均检查了不同源比例的实帧，成片复核了 12 秒循环接缝、左右裁切及 390 px 与 1280 px 网页预览的裁切切换。

如需回退，以本次 Git 差异为准，仅撤回包框安全区、过渡与对应验收段落。
