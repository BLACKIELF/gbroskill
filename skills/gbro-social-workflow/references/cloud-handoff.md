# 云端制作与接手

先恢复本篇作品清单、最新完整稿、已确认片头片尾和实际平台状态；新版号、成功生成或参数一致不等于用户已接受。安装 Skill 后仍需完整仓库的 `runtime/voice/` 才能调用随包配音脚本，详细命令见[云端接手说明](https://github.com/BLACKIELF/gbroskill/blob/main/docs/CLOUD-HANDOFF.md)。

## 必须保留的制作要求

- 全平台新视频统一 9:16、至少 1080×1920，只有用户当次明确指定其他画幅才例外；原始素材按原比例内部存档，合成不拉伸、不裁关键内容。
- 独立封面按[平台规格](platform-specs.md)分别制作，视频号横、竖封面分别检查，品牌与标题按[安全区](platform-specs.md#视频号标题与品牌安全区)保留完整，不能把视频的 9:16 套给所有封面。
- 图片框使用[多色 12 秒呼吸流光](breathing-frame.md)，保留青蓝、紫蓝、金绿和玫红；整幅背景使用[4 秒红蓝球面光线](../assets/black-glass-loop.html)。两个循环独立，素材本身不随光晕缩放。
- 保留完整真实来源截图、原始文字与必要上下文；图文口播在竖版内重新排版，不重画新闻原帖或软件 UI。已确认图卡、官方 Logo、原生文字与片尾不擅自换成新 AI 宣传卡。
- 固定字体、字号、边距和品牌配色按 [image-style.json](../assets/image-style.json)。模板能够使用浏览器替代字体不等于该字体已获准交付；云端缺 PingFang SC 时先取得该环境可合法使用的已授权字体，或由用户明确接受替代方案，不能静默降级后称同款。
- TikTok 和 X 必须有真实完整英文口播与英文文章、标题、发布正文；英文／双语字幕不能替代英文音轨。实际来源截图中的原文保留。
- [G4 声音](aigoodbro-voice.md)使用原始 `reference.wav` 和准确中文 `ref_text`，`instruction` 显式为空；固定模型、revision、参数与已接受样音。英语只换待配正文。任一处有问题默认全文连同片尾重配，用户明确指定局部处理才例外。
- 已确认正文、片头、片尾逐字保留；目标语言只做对应翻译，不另换口号。某篇用户明确接受的例外仅写本篇清单，不扩展成通用规则。

## 跨环境边界

当前指定声音只在 Apple Silicon Mac / Python 3.12 / 固定 MLX 依赖上实测。普通 Linux／Windows 云端没有随包已验证的同声音生成路线，不能改用其他 TTS、模型或参考音冒充。先运行仓库 `runtime/voice/preflight.py`，检查本机条件与模型完整性；预检只读，不下载、安装或生成声音。

环境缺项只暂停依赖的步骤：继续稿件、来源、封面布局和工程；本篇已有已接受完整干声时按哈希直接复用。确需新配音时，把完整确认稿交给已验证的 Apple Silicon 执行端，收回完整干声及回执再合成；不自动暴露本机服务或部署云桥。参考音、原始试听、已接受样音和参数实际随包提供，固定模型通过许可接受和逐文件哈希流程单独获取。

成片逐项检查真实尺寸、完整音轨、解码、首中尾、字幕同步、安全区、来源文字和实际播放；固定参数及 ASR 不能代替听感。云端交付、飞书附件回读、平台提交和公开结果分别记录。当前环境缺账号或发布入口时保留本地成果与具体缺项，不伪称已送达或已公开。
