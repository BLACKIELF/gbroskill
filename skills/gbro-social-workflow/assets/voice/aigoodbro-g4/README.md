# AiGoodBro G4 声音样本

`reference.wav` 是用户选择的片尾原始干声，7.04 秒、24 kHz、单声道；后续同条口播固定用它作参考。`sample-whole.wav` 是用同一参考一次生成的 70.72 秒整段口播示例，正文和片尾均为新生成，没有拼接旧段；此次生成仍待用户听感确认，准确输入及参数见 `profile.json`。两者均为合成音频，无背景音乐。新生成音色仍须逐段听辨，样本不是额外训练出的模型。

样音由 Breeze TTS 2 MLX 4bit 生成，作为非商业研究与复现示例分享。模型和输出受随附 LICENSE 约束，不受仓库根目录 MIT 许可替代；商业使用需要权利人的单独授权。不授予商标、真人身份或其他素材权益。
