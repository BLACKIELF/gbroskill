# AiGoodBro G4 声音样本

`reference.wav` 是用户保留的 G4「轻快伙伴」原始模型干声，8.32 秒、24 kHz、单声道；每次生成均使用这份文件作为克隆参考。`sample.wav` 是同一原始样本仅做恒定音量调整的试听版，没有改音高、速度或音色。准确参考文字、原始指令、参数与两个文件的 SHA-256 见 `profile.json`。

品牌参考固定在已选原件；新生成口播、片尾或尚未验收的音频只保留在作品工程，不自动升级为品牌参考或随包标准样音。用户明确另选声音时才更新参考，并保留旧样本。每次完整口播仍须单独听感验收。

样音由 Breeze TTS 2 MLX 4bit 生成，作为非商业研究与复现示例分享。模型和输出受随附 LICENSE 约束，不受仓库根目录 MIT 许可替代；商业使用需要权利人的单独授权。不授予商标、真人身份或其他素材权益。
