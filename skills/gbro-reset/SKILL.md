# GBro 重置消息 · 完全固定模板

这是强制规范。目标：用户一发消息，5 分钟内交齐成品。**不改版式、不加内容、不出候选、不问风格。**

## 只需要从消息里提取 3 个值

| 值 | 取法 |
|---|---|
| `mode` | `forecast` 预计重置 / `done` 已经重置 / `card` 重置卡已发放 |
| `date` | 北京时间日期 `YYYY-MM-DD` |
| `time` | 北京时间 `HH:MM`；来源是 UTC 等其他时区就换算成北京时间；`card` 没给时间可省略 |

时间只写“左右”，不写“最晚/确认到账”。拿不准是预计还是已发生，用 `forecast`。只有这 3 个值缺失才问用户，其他一律不问。

## 一条命令

```bash
python3 <本skill目录>/scripts/make_reset.py --mode forecast --date 2026-11-02 --time 16:00
```

- 默认输出到 `/Volumes/4t/AiGoodBro-GBro/<YYYYMMDD>-Codex重置消息/`；4T 不在或剩余不足 20 GiB 时自动改到 `~/Movies/AiGoodBro-GBro/`。同名自动升版本号，不覆盖旧版；显式指定空间不足的 4T 输出目录会停止写入。
- 配音自动调本机 BreezeTTS2（`127.0.0.1:7862`），G4 纯克隆、`instruction=""`、seed 1447，整段一次生成。当前配音工作台的生成文件固定写到 4T；4T 不在或剩余不足 20 GiB 时跳过自动配音，生成文件标“待配音”，不可当成完整配音版发布。已有本地 G4 干声可通过 `--voice-file` 使用。
- 没有本机配音服务（云端 / Muse / Grok Bot）：加 `--no-voice` 先出 BGM 版，回执标“待配音”；或用 `--voice-file 中文.wav --voice-file-en 英文.wav` 套用已有 G4 干声。**不能换别的声线顶替。**
- 依赖：Python 3 + numpy + playwright（chromium）+ ffmpeg。
- BGM：`assets/bgm/` 有 5 首代码原创、各 60 秒的立体声曲（pulse 电子脉冲 / lofi 轻松 / tech 科技四拍 / ambient 氛围 / bright 明快），首尾淡入淡出，剪辑时可任意截取。重置视频默认 `--bgm tech`；可显式选其他曲，或用 `--bgm auto` 按日期轮换。配音时自动压到人声下方。要更长或重做：`python3 scripts/make_bgm.py --seconds 120`。

## 固定成品（不增不减）

| 文件 | 用途 |
|---|---|
| `Codex重置-中文竖版-*.mp4` | 1080×1920，中文 G4 + BGM；抖音/视频号/微博/快手/B站/小红书。无 G4 时文件名加“待配音” |
| `Codex重置-英文竖版-*.mp4` | 1080×1920，英文 G4 + BGM；X/TikTok/YouTube。无 G4 时文件名加“待配音” |
| `封面-中文/英文-9比16 / 3比4 / 16比9-*.png` | 各平台独立封面 |
| `全平台文案-*.md / .json` | 微博、快手、抖音、视频号、小红书、B站、公众号、X、TikTok、YouTube |
| `记录/出片回执-*.json` | 时长、哈希、配音状态 |

## 固定版式（模板写死在脚本里，禁止改）

黑色毛玻璃 + 红蓝球面 4 秒循环背景 → 头像 + 三色 `AiGoodBro` → `CODEX 重置消息` → 大标题（预计重置 / 已经重置 / 重置卡已发放）→ 北京时间日期 + 大号钟点“下午4点左右” → 胶囊提醒“谨慎使用重置卡，合理安排使用额度”。最后 2.8 秒主画面淡出、落版卡淡入：头像 + “关注 AiGoodBro，第一时间获取重置消息！”。视频里这句只显示一次（主画面不再写），口播也只念一次；封面没有落版卡，底部保留这句一次。

固定口播（中文）：“Codex 重置消息。预计北京时间，X月X日，下午X点左右重置。谨慎使用重置卡，合理安排使用额度。关注 AiGoodBro，第一时间获取重置消息！”英文同义，末句 “Follow AiGoodBro for reset news first!”。约 12–15 秒。

固定话题：`#codex #aigoodbro #tibo #codex重置`；抖音 +`#AI编程`（共 5），小红书 +`#AI工具 #AI编程`，TikTok +`#ai`（共 5），快手 4 个。

## 四类视频落版卡（非重置视频也用）

规则以 [视频落版文案](../gbro-social-workflow/references/delivery.md#视频落版文案) 为准，画面沿用已确认的四类落版样片：头像、三色品牌字、主句和浅灰次行居中排列；资讯长句自动缩至安全区内。主句 = 口播末句，写进完整口播稿、整段一次生成 G4，不单独生成拼接。非重置类画面另加次行“第一时间获取重置消息！”（只显示不念），不第二次写“关注 AiGoodBro”；重置类只有主句。

| `--kind` | 主句（口播末句） | 次行 |
|---|---|---|
| `skill` 免费/其他 Skill 推荐、提示词、Skill 教学 | 关注 AiGoodBro，获取更多免费 Skill！ | 第一时间获取重置消息！ |
| `tutorial` 设计、AI 编程、工具、自动化、剪辑、排查等教程 | 关注 AiGoodBro，获取更多教程！ | 第一时间获取重置消息！ |
| `news` AI 资讯、模型发布、产品更新、工具动态 | 关注 AiGoodBro，第一时间获取Ai资讯消息！ | 第一时间获取重置消息！ |
| `reset` 重置预告、已重置、重置卡 | 关注 AiGoodBro，第一时间获取重置消息！ | 无 |

```bash
python3 <本skill目录>/scripts/make_endcard.py --kind tutorial [--lang en]
```
输出透明落版层（叠到成片最后 2.8 秒）和带背景静帧，默认放 `~/Movies/AiGoodBro-GBro/落版卡/`。

## 禁止项

- 不写长文、不做教程段、不加来源截图卡、不做多版本候选、不加宣传卡片尾。
- 不改字体、颜色、布局、口播句式、落版句。要改模板，只有用户明确说“改模板”才改，并同步 GitHub。
- 不把“预计”写成“已到账”；不编造时间。

3. 给用户的回复只列：成品路径、配音状态、各平台是否已发。
