# GBro 视频强制规范（冻结版 · 1103v1）

本文件是 AiGoodBro／GBro 视频的唯一硬约束。规则来自维护者逐条确认与纠正，**执行者不得自行改动、放宽或“优化”**。改动只有一种途径：维护者明确说“改模板／改规范”，并同步 GitHub 与本机安装版。

任何人拿到本包，按“最小做法”跑一遍测试片（见[验收](#验收测试片)），再用 `check_video.py` 自动核查，就能判断是否达到维护者要的效果。

## A. 画幅与交付

| # | 规则 | 机器可查 |
|---|---|---|
| A1 | 新制作、包装、混剪、待发布视频**只输出 9:16、至少 1080×1920**；不给其他画幅选项 | `check_video.py` 第一项 |
| A2 | 原始素材内部保留原比例，不拉伸；16:9 原片完整居中放入 9:16，上下黑色毛玻璃 | 目视 |
| A3 | 封面是独立规格（视频号横竖各一、抖音/TikTok 独立竖封面等），**不把 9:16 套给所有封面** | 目视 |
| A4 | 输出前核真实写入卷的剩余空间；4T 不在或不足 20 GiB 时改内置盘并明确说明。创作不出黑边、不降规格凑容量 | 回执 |

## B. 背景（呼吸光底）

| # | 规则 |
|---|---|
| B1 | **整支视频全程使用连续红蓝球面呼吸光底**：字幕段、换卡、落版卡都有动态底，不能做成黑底静态幻灯片 |
| B2 | 背景贯穿整幅画布，不拆成上下两块；球面轮廓基本稳定，光线沿弧面连续移动，默认 4 秒一轮 |
| B3 | 换卡、切落版不重置背景相位；不做硬切黑场 |
| B4 | 4 秒球面背景与 12 秒多色图片呼吸框是两个独立动效，不能互套配色 |

固定素材：`assets/bg-loop-1080x1920.mp4`（4 秒、1080×1920、可无缝循环）。

## C. 版面与字幕

| # | 规则 |
|---|---|
| C1 | **字幕是直接文字**：不加方框、圆角底板、半透明卡片或描边窗口。来源截图自带的呼吸边框保留，不因此删掉 |
| C2 | 断行按语义；闭合标点 `，。！？；：、）》】」』”’` **不能出现在行首**，也不能单独成行 |
| C3 | 不通过删标点掩盖断行问题，也不擅改已定字体字号硬塞；断行后文字与原文逐字一致 |
| C4 | 每张卡都要逐张查看实际渲染与手机可读性，不能只修第一张 |
| C5 | 品牌 `AiGoodBro` 用三色（Ai 浅蓝 #9BD9F8 / Good 白 / Bro 珊瑚红 #FF6B62），头像沿用既定卡通头像 |
| C6 | 分镜卡不超过 12 张；竖版正文一卡一段，不堆长文 |

## D. 落版（尾板）

| # | 规则 |
|---|---|
| D1 | **四类主句固定**，主句 = 画面末句 = 口播最后一句 |

| 类别 | 主句（显示且口播） | 次行（只显示，不念） |
|---|---|---|
| 免费/其他 Skill 推荐、提示词教程、Skill 教学 | 关注 AiGoodBro，获取更多免费 Skill！ | 第一时间获取重置消息！ |
| 设计、AI 编程、工具操作、自动化、剪辑、排查等教程 | 关注 AiGoodBro，获取更多教程！ | 第一时间获取重置消息！ |
| AI 资讯、模型发布、产品更新、工具动态 | 关注 AiGoodBro，第一时间获取Ai资讯消息！ | 第一时间获取重置消息！ |
| 重置预告、已重置、重置卡 | 关注 AiGoodBro，第一时间获取重置消息！ | 无 |

| # | 规则 |
|---|---|
| D2 | **每个落版都必须出现“第一时间获取重置消息！”**：非重置类放次行（可不念），重置类由主句包含，不重复 |
| D3 | **不重复写“关注 AiGoodBro”**：主句已经包含，次行只写重置提示 |
| D4 | 落版卡是全画布固定层，**不加方框/窗口边框**，不重复品牌标题或正文标题 |
| D5 | 落版出场时长要容纳完整末句；按末句时长留足，并至少保留 0.6 秒余量，不能机械按固定 2.8 秒裁掉 |
| D6 | 交叉题材按本篇主要目的归类：教操作归教程，报道更新归资讯；不新增第五类 |

## E. 配音（G4）

| # | 规则 |
|---|---|
| E1 | 固定使用 G4 纯克隆：原始参考 SHA-256 `3b08420d43718ae1a2e4dbbec833e4b2803f0f20394b1c7619ecc89c46a6aa21`，`instruction` 显式空，seed 1447，temperature 0.8，repetition_penalty 1.1，top_p 1.0，top_k 50，24 kHz。不能换其他声线顶替，也不能覆盖原始参考 |
| E2 | **全文与落版主句在同一份完整稿里生成**；不允许只补一句、拼接旧段或保留旧尾句 |
| E3 | **最后一句必须完整**，不能吞尾音。以“解码样本数 = 生成帧数 × 1920”核对，ASR 识别到末字不能当通过 |
| E4 | 整稿很长时按工作台的分段规则在同一次请求内生成（每段自然句界），但落版主句必须单独成最后一段，确保完整 |
| E5 | 配音听感要真给用户试听；技术检查通过不等于用户接受 |
| E6 | 没有可用配音端（云端、Muse、Grok Bot）时输出“待配音”版，文件名标注，不能报成配音版 |

## F. 音乐

| # | 规则 |
|---|---|
| F1 | BGM 使用 `assets/bgm/` 下代码原创的五首 60 秒曲（`pulse` `lofi` `tech` `ambient` `bright`）。维护者已确认 **tech 为重置视频默认**；本条只固定重置，不扩成所有题材永久 tech |
| F2 | 用户或文档指定了具体曲目时，用指定素材并核时长与哈希；不能凭近似文件名选曲，也不重新生成别的曲子冒充原来的 |
| F3 | 口播在音乐之上，人声必须清楚；不把只有音乐、没有口播的片子报成配音版 |

## G. 交付与状态

| # | 规则 |
|---|---|
| G1 | 先给可看/可听的成品与准确路径，再谈过程和参数；不把技术交接转嫁给用户 |
| G2 | 飞书每条文字首行写 `（平台）`，前后不加分割线；媒体紧随对应平台文字 |

| G4 | 设备任务（如手机 Mika）以实际界面和重开草稿为准；自述、队列状态、上传进度不算成功；不指引用户点不存在的按钮 |
| G5 | 小红书仍暂停自动搜索与直接发布，只存草稿并等维护者明确叫发布 |

| G7 | 回音谷 AI 是独立品牌：可用非 G4 音色与科技版式，**不得改写 GBro 的 G4、配色与模板** |

## 验收测试片

两条命令即可让人确认拿到的是同一套效果：

```bash
# 1. 出 12 秒测试片（重置句 + 教程落版交替检查版式，非真实资讯）
python3 scripts/make_test_video.py --out ~/Movies/AiGoodBro-GBro/验收测试片

# 2. 自动核查
python3 scripts/check_video.py <上面的 mp4> --voice <对应的口播 wav> --manifest <记录/出片回执.json>
```

`check_video.py` 硬项全绿只说明技术上符合 A/B/C/E 的可查部分；**落版文字、字幕无框、手机可读性与音色必须目视和试听确认**。

## 常见违规（历史实际发生）

- 字幕擅自加圆角底板；尾板被套进带框窗口。
- 句号跑到下一行开头。
- 只在片头片尾有背景，正文是黑底。
- 末字被截掉（解码按尺寸裁切，少 0.24 秒）。
- 用旧 17 秒配乐顶替指定的一分钟 BGM。
- 把“预计重置”写成“已到账”，或编造时间。
- 把技术检查通过报成用户已经接受。
