# AiGoodBro 品牌预设

当前日常图文沿用红、蓝、白：浅白底承托内容，蓝色建立主层级，红色强调一个重点。约 60/30/10 为视觉权重参考，不是逐像素硬性黄金分割。画面以真实证据与内容为主，头像和字标缩小，不能用重绘界面冒充截图。

历史蓝奶油方块风格的近似色锚为浅天蓝 `#B1D4F6`、象牙白 `#FBF5EE`、钴蓝 `#0256EE`、朱红 `#E74732`，它是可选历史风格，不覆盖当前红蓝白要求，不自动添加黄绿点缀。完整排版规则见 [visuals.md](../skills/gbro-social-workflow/references/visuals.md)。

角色原图、二维码和已确认私人样图不随包提供。使用自己的已授权素材，缺少参考时沿用文字层级与色彩角色，不伪称复现了未读到的样图。许可不授予 AiGoodBro 商标或账号使用权。
