# 工具边界

| 入口 | 可以做 | 必须单独确认 |
|---|---|---|
| GBro / Skill | 组织素材、写作、设计、选择工具、验收 | Skill 本身不登录，不保证外部工具已装 |
| SAU 小红书／抖音 | 登录、会话检查、视频／图文、定时 | 上传通常真实提交；没有通用 dry-run；指定话题和封面要读回 |
| SAU 微博视频 | 视频、封面、标题、话题、原创／二创及显式声明 | 不代选声明；普通帖与头条文章是另一条入口 |
| SAU B站 / biliup | 视频、封面、分区、话题、定时 | 包装器转载来源字段有缺口，不能把投稿成功当声明正确 |
| SAU 视频号 | 视频、封面、定时；显式 draft 可保存远端草稿 | 草稿也上传素材；审核不等于公开 |
| baoyu X | 默认填稿，显式 submit 发布；视频／长文章有独立脚本 | 文章权限、媒体完整性、最终 URL |
| baoyu 微博 | 填普通帖或头条文章编辑器 | 脚本不完成最后的公开发布 |
| autotok CLI/MCP | 独立账号登录／校验、TikTok 视频和定时 | 上传是真实发布，独立封面、商业披露能力有局限；不推定美国账号地区 |
| Metricool | 已连接品牌的分析、排期、更新与部分审批流程 | 自己的连接和套餐权限；排期 URL 不是作品 URL；送审可能通知他人 |
| stylewx MCP | 排版、渲染、校验、公众号草稿 | 草稿、发表、群发各有权限，三者不同 |
| 微信／小程序官方接口 | 由具体官方权限决定 | 小程序不是通用发帖工具，内容同步不等于代码提审 |
| Agent-Reach 与浏览器 | 选择已接通的正文／评论／媒体读取路线 | 路由说明不安装后端；可见片段不等于读完；评论数量不等于评论正文 |
| 飞书 CLI | 已授权资料读取、文档、消息和文件交付 | 使用者自己的应用、身份、接收方；安装不授权发送 |

详细字段、临发布核验和读取边界保持在[GBro 平台工具参考](../skills/gbro-social-workflow/references/platform-tools.md)，避免维护两套冲突规则。所有支持话题的渠道使用当前品牌项；数量与格式见[平台规格](../skills/gbro-social-workflow/references/platform-specs.md)，公众号用户标签不当成文章话题。

默认静态验证只执行本地检查和工具帮助，不上传“测试帖子”。登录、工具发现、真实内容发布的证据不能互相代替。用户限定内置浏览器时，其他 CLI／Chrome 工具存在也不能擅自切换。
